# 保险资管学习地图（Insurance Asset Management — Study Map）

> 本文件是对微信公众号"漫绘资管"12 篇保险资管系列的结构化整理，作为 [awesome-ai-quant](../README.zh-CN.md) 的领域知识板块。
> 概念与数据归属原作者；本文件做知识结构化重组，供学习与二次创作。微信链接建议在微信客户端内打开。
> 数据时点：2025 年末—2026 年三季度（各篇口径见下文速查表）。

## 0. 为什么放在 AI × 量化清单里

三个理由：

1. **它是固收量化的最大甲方场景**。中国保险资金运用余额 40.82 万亿（2026Q2），债券占一半——利率债、超长债的边际定价者是险资。做固收量化，不懂约束方等于只看了一半的棋盘。
2. **约束驱动的配置范式**。公募量化是预测驱动（alpha），险资是约束驱动（负债匹配）。两套范式对工程系统的要求完全不同——后者是"约束求解 + 情景模拟"，恰好是量化工程里最像软件工程的部分。
3. **运营链路正在被 Agent 重构**。系列最后三篇（技术体系→智能化转型→Claude Code 实战）就是 AI 工程师在这个行业的切入面。

## 2. 核心机制一：三个池子（一切的起点）

**预定利率三档**（2025-09 起执行）：传统 2.0% / 分红 1.75% / 万能 1.0%。

| 维度 | 传统账户 | 分红账户 | 万能账户 |
|---|---|---|---|
| 刚性部分 | 全部（2.0% 锁几十年） | 1.75% 保底 + 浮动 | 1.0% 最低保证 |
| 超额归属 | — | 可分配盈余 ≥70% 给客户（红线 3.20% 需论证） | 结算利率随实际投资收益 |
| 亏了谁兜底 | 公司（利差损） | 分红缩水，公司不掏自有资金 | 穿透保单账户价值须 15 个工作日内自有资金补足 |
| 关键监管约束 | 偿付能力分档，权益上限 10%–50% | 单独账户 + 特别储备（以丰补歉） | 流动性资产 ≥5%、另类 ≤45%、单一项目 ≤5%、储备补差单次 ≤25bp |
| IFRS17 计量 | BBA（当场判卷） | VFA（CSM 吸收、逐期释放） | VFA 或 MGMM |
| 权益偏好 | 高股息进 OCI（只拿分红不进利润表） | 略高于传统（有 CSM 缓冲） | 收敛 |

**推导出的现象**：险资举牌银行/水电/运营商高股息 = 传统账户 OCI 逻辑；分红险放量（2025 保费 +18.06%）= 权益仓位上行的负债端解释；"保险资金"不是一种风险偏好，是若干个账户各自的约束。

## 3. 核心机制二：配置决策链（SAA/TAA/ALM 约束栈）

```
负债特征（期限 / 成本 / 波动承受力）
    ↓
硬约束栈：偿付能力（偿二代资本占用）→ 权益比例上限（分档 10%–50%）
          → 有效久期缺口 ±5 年（2027-01-01 施行）→ 净投资收益覆盖率 ≥100%
    ↓
均值方差 + 蒙特卡洛（几千情景跑偿付能力击穿概率）→ SAA 中枢
    ↓
SAA 画出偏离带 → TAA 带内微调（幅度小、节奏慢、"配置加交易"）
    ↓
季度回顾 → 校准
```

- 理论底座：Brinson/Hood/Beebower——资产配置解释 91.5%（1991）/ 93.6%（1986）的收益波动。
- 现实结构（2026Q2）：债券 50.52% / 股票 10.41% / 基金 5.82% / 存款 7.70% / 长股投 7.62% / 其他（非标为主）17.9%。
- ALM 的数字源头：负债久期 13–16 年 vs 资产约 5.6 年 → 缺口 -7 至 -9 年 → 利率下行的净资产杀伤 + 超长债的四条刚需（期限长、信用近零、免税 + 偿二代最优资本占用、险资在超长端有边际定价权——2026 年 6-7 月净买入 30Y+ 国债 455 亿，同期银行券商净卖出）。
- 利差损机制：10Y 国债 3.14%（2020）→ 1.67%（2026-09），存量保单成本 3–3.5%，2025 上市险企净投资收益率均值 3.35%——收益与成本正在贴地摩擦。

## 4. 行业格局速查

- 三种资金：系统内约 70.56%（2024 末）/ 第三方约 7 万亿（银行 3.48 万亿 + 养老金 2.8 万亿）/ 保险资管产品（仅合格机构投资者，散户买不到）。
- 商业模式对比：公募赚费率（主动权益 ≤1.2%/年 + 渠道分账），保险资管赚规模（9.68bp + 轻成本 + 高粘性）。
- 产品四类：组合类、债权投资计划、股权投资计划、资产支持计划；全生命周期六环节（设计登记→募集→投资运作→披露→清算），每环节有对应系统（TA/估值/信披/中保登报送）。

## 5. AI 落地点（系列第 10–12 篇）

- **技术栈现状**：前台（投研/OMS/EMS）+ 中台（数据湖/风控引擎）+ 后台（估值核算/托管对接）；供应商版图 Aladdin、SimCorp、恒生、O32、赢时胜等。
- **转型叙事**：流程自动化 → 认知自动化；SOP 拆解为原子 Skill，数字员工（合规 Agent/风控 Agent/交易 Agent/运营 Agent/估值 Agent）动态编排；研发侧 AI 原生 DevOps（需求洞察→代码生成→智能仿真→自愈运维→AI 产出质量评测）。
- **Claude Code 六场景**（已在生产可用）：报告批量比对（20 份 2 天 → 10 秒）、agent-browser 表单自动化（估值系统参数维护）、canvas/frontend 设计、pptx skill 路演材料工厂、浏览器爬虫 + xlsx、skill-creator 团队技能沉淀。
- **对 AI 工程师**：这个行业的第一落点不是投研，是运营——确定性高、规则明确、人工密集，是 agent 的完美靶场。
